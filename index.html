The Secret of Moluccas: Cyber Detective

Dokumen Desain Game (GDD) & Media Pembelajaran Interaktif
Mata Pelajaran: Informatika
Fase / Kelas: E / X (SMA)
Materi Utama: Berpikir Komputasional

1. Identifikasi & Analisis Instruksional

Game ini dirancang sebagai media pembelajaran inovatif untuk mengontekstualisasikan pilar-pilar Berpikir Komputasional (Computational Thinking) dalam kurikulum Informatika Fase E (Kelas 10)[cite: 1, 2]. Melalui pendekatan Visual Novel dan Point-and-Click Adventure, siswa tidak hanya menghafal teori, tetapi mengaplikasikannya langsung untuk memecahkan masalah (problem-solving) dengan memanfaatkan kekayaan narasi lokal Maluku Utara[cite: 1, 2].

Komponen Deskripsi Operasional
Capaian Pembelajaran (CP) Siswa mampu menerapkan strategi algoritmik standar untuk menghasilkan beberapa solusi dalam menyelesaikan persoalan dengan data diskrit bervolume besar atau struktur kompleks melalui dekomposisi, pengenalan pola, abstraksi, dan algoritma[cite: 1, 2].
Sasaran Pengguna Siswa SMA Kelas X (Rentang usia 15-16 tahun)[cite: 1, 2].
Platform Target Web Browser (Responsive HTML5/WebGL) & Mobile Smartphone (Android/iOS via Cordova/Unity WebGL wrapper)[cite: 1, 2].
Pendekatan Pedagogis Game-Based Learning (GBL), Contextual Learning (Kearifan lokal rempah Maluku Utara), dan Scaffolding (Peningkatan kompleksitas masalah bertahap)[cite: 1, 2].

2. Struktur Narasi & Alur Game

2.1 Logline & Sinopsis

Di masa depan (Tahun 2085), perubahan iklim global mengancam kepunahan vegetasi endemik dunia[cite: 1, 2]. "The Bio-Preservation Formula"—sebuah algoritma digital enkripsi hayati yang mampu menjaga daya tahan pohon Cengkeh (Syzygium aromaticum) dan Pala (Myristica fragrans) purba dari serangan virus tanah—telah dicuri dari laboratorium pusat oleh bio-hacker tak dikenal[cite: 1, 2]. Jejak digital pelaku mengarah ke Hutan Tropis Lindung di wilayah Maluku Utara[cite: 1, 2]. Pemain bertindak sebagai Detektif Digital yang dikirim ke pulau misterius ini untuk melacak, merekonstruksi data, dan membuka brankas penyimpanan formula sebelum enkripsinya mengunci secara permanen[cite: 1, 2].

2.2 Peta Perjalanan Pemain (Player Journey)

Permainan dibagi menjadi 3 zona hutan yang merepresentasikan eskalasi tantangan berpikir komputasional[cite: 1, 2]:

  1. Zona Sibu (Gerbang Hutan - Level 1): Area vegetasi cengkeh padat. Fokus pada pemilahan data rusak (Dekomposisi)[cite: 1, 2].
  2. Zona Akelamo (Lembah Sungai - Level 2): Labirin hutan pala. Fokus pada pemetaan rute efisien (Pengenalan Pola & Pencarian)[cite: 1, 2].
  3. Zona Goaria (Pohon Pala Purba - Level 3): Inti ekosistem. Fokus pada penyusunan logika eksekusi brankas (Abstraksi & Algoritma)[cite: 1, 2].

5. Rancangan Teka-Teki Berbasis Informatika (Level 1 - 3)

5.1 Level 1: Dekomposisi Masalah (Zona Sibu)

Tujuan Edukasi: Menguji kemampuan siswa memecah masalah kompleks menjadi sub-masalah terkecil, mengidentifikasi komponen yang rusak/eror dari sekumpulan data masukan[cite: 1, 2].

Narasi Tantangan: AI Gawai menangkap sinyal bahwa 4 helai daun dari pohon Cengkeh Utama membawa potongan kode biner yang corrupt (mengalami kerusakan bit)[cite: 1, 2]. Siswa disajikan panel AR berisi 5 helai daun cengkeh yang masing-masing merepresentasikan sebuah string biner berukuran 8-bit beserta bit paritasnya (Parity Bit Check - Genap)[cite: 1, 2]. Pemain harus melakukan dekomposisi memeriksa satu per satu daun untuk menemukan daun mana yang tidak valid[cite: 1, 2].

Aturan Logika: Pada sistem paritas genap, jumlah angka '1' dalam string 8-bit ditambah bit paritas harus berjumlah GENAP[cite: 1, 2]. Jika GANJIL, maka daun tersebut rusak (Membawa Kode Eror)[cite: 1, 2].

ID Daun Data 8-Bit Bit Paritas Total Angka '1' Status (Analisis Dekomposisi)
Daun A 10101000 1 4 (Genap) Valid (Normal)[cite: 1, 2]
Daun B 11001110 1 6 (Genap) Valid (Normal)[cite: 1, 2]
Daun C 10111010 0 5 (Ganjil) EROR (Pilihan Benar untuk Diklik!)[cite: 1, 2]
Daun D 00001111 0 4 (Genap) Valid (Normal)[cite: 1, 2]

Feedback & Edukasi Visual:

  • Jika Benar (Klik Daun C): Sinyal distorsi hilang, daun menyala hijau. Animasi HUD: "Dekomposisi Berhasil! Kerusakan diisolasi pada sub-blok Daun C. 1 Potongan Formula didapatkan (+100 Poin)."[cite: 1, 2]
  • Jika Salah (Klik Daun A/B/D): Layar bergetar merah ringan. Memunculkan jendela edukasi: "Analisis Logika Keliru. Ingat kembali prinsip Dekomposisi: Periksalah tiap elemen data secara terpisah. Cek jumlah angka '1' pada daun tersebut. Pada sistem paritas genap, total angka '1' (termasuk bit paritas) mutlak harus genap. Silakan analisis ulang!"[cite: 1, 2]

5.2 Level 2: Pengenalan Pola (Zona Akelamo)

Tujuan Edukasi: Menguji kemampuan siswa mengenali keteraturan/pola spasial dan menerapkan langkah algoritma pencarian rute terpendek (Breadth-First Search / Djikstra sederhana) pada sebuah graf[cite: 1, 2].

Narasi Tantangan: Detektif harus melintasi labirin rawa hutan Pala menuju koordinat pemancar[cite: 1, 2]. Di layar tersaji peta topografi digital berbasis Graf (Node = Pohon Pala Bertanda Huruf A, B, C, D, E, F; Edge = Jalur setapak dengan angka bobot jarak dalam meter)[cite: 1, 2]. Bio-hacker mengaktifkan sistem keamanan perimeter: Detektif hanya memiliki sisa energi gawai sebesar 15 Unit[cite: 1, 2]. Setiap meter perjalanan menghabiskan 1 unit energi[cite: 1, 2]. Siswa harus mengenali pola jalur dan memilih urutan node rute yang paling efisien dari Node A (Awal) ke Node F (Akhir)[cite: 1, 2].

Koneksi Graf & Bobot Jalur:

  • Node A terhubung ke: B (4 meter), C (2 meter)[cite: 1, 2]
  • Node B terhubung ke: D (5 meter), E (1 meter)[cite: 1, 2]
  • Node C terhubung ke: D (8 meter), E (6 meter)[cite: 1, 2]
  • Node D terhubung ke: F (6 meter)[cite: 1, 2]
  • Node E terhubung ke: F (3 meter)[cite: 1, 2]

Pilihan Jawaban yang Disediakan ke Siswa:

  1. Jalur 1: A → B → D → F (Total Jarak = 4 + 5 + 6 = 15 meter)[cite: 1, 2]
  2. Jalur 2: A → C → E → F (Total Jarak = 2 + 6 + 3 = 11 meter)[cite: 1, 2]
  3. Jalur 3: A → B → E → F (Total Jarak = 4 + 1 + 3 = 8 meter) [PILIHAN PALING OPTIMAL][cite: 1, 2]
  4. Jalur 4: A → C → D → F (Total Jarak = 2 + 8 + 6 = 16 meter → Energi Habis!)[cite: 1, 2]

Feedback & Edukasi Visual:

  • Jika Benar (Memilih Jalur 3): Detektif meluncur cepat melalui jalur aman. Animasi HUD: "Pola rute teridentifikasi! Rute A-B-E-F menghemat daya gawai hingga 47%. Area Berikutnya Terbuka (+150 Poin)."[cite: 1, 2]
  • Jika Salah (Memilih Jalur Lain): Detektif diperlihatkan terjebak jalan buntu/berlumpur, indikator baterai gawai drop. Edukasi: "Pola pencarian tidak optimal. Pengenalan Pola dalam graf mengharuskan kita menjumlahkan seluruh bobot tepi pada setiap kemungkinan jalur alternatif sebelum melangkah. Jalur pilihanmu terlalu panjang dan menghabiskan resource baterai. Coba hitung kembali kombinasi jalur terkecil!"[cite: 1, 2]

5.3 Level 3: Abstraksi & Algoritma (Zona Goaria)

Tujuan Edukasi: Menguji kemampuan siswa melakukan abstraksi (mengabaikan informasi tidak relevan, memfokuskan pada variabel kunci) dan menyusun instruksi logis berurutan (Pseudocode/Algoritma) menggunakan struktur kontrol perulangan (Looping) dan percabangan (Kondisional)[cite: 1, 2].

Narasi Tantangan: Detektif tiba di depan Pohon Pala Purba yang memiliki brankas bio-mekanik tertanam di batangnya[cite: 1, 2]. Untuk membukanya, siswa harus mengonfigurasi mekanisme kunci kombinasi gigi putar digital[cite: 1, 2]. Siswa disajikan cuplikan kode instruksi yang rumpang (memiliki bagian kosong) di panel instrumen gawai mereka[cite: 1, 2]. Mereka harus menyeret dan melepaskan (drag-and-drop) potongan logika pseudocode yang tepat agar mesin berputar memproses kunci sesuai variabel target[cite: 1, 2].

Kondisi Variabel Konseptual:

  • Jumlah gigi putar brankas (G) = 3 gigi[cite: 1, 2].
  • Setiap gigi putar harus diputar searah jarum jam sebanyak X kali, di mana X ditentukan oleh nomor indeks gigi tersebut dikalikan 2[cite: 1, 2].
  • Informasi distraksi (harus diabaikan lewat proses Abstraksi): Tinggi pohon pala (25 meter), ketebalan kulit kayu (12 cm), warna lumut pohon (hijau tua)[cite: 1, 2].

Rancangan Blok Pseudocode Rumpang:

ALGORITMA Buka_Brankas_Pala
DEKLARASI variabel i, x : integer
MULAI
   FOR i ← 1 TO 3 DO
      [ Bagian Rumpang Kosong 1 ]
      WHILE (x > 0) DO
         Putar_Gigi_Searah_Jarum_Jam(i)
         [ Bagian Rumpang Kosong 2 ]
      ENDWHILE
   ENDFOR
   Cek_Kunci_Validasi()
SELESAI
[cite: 1, 2]

Opsi Drag-and-Drop yang Tersedia bagi Siswa:

  • Pilihan M1: x ← i * 2[cite: 1, 2]
  • Pilihan M2: x ← x - 1[cite: 1, 2]
  • Pilihan D1 (Distraksi): x ← tinggi_pohom * 2[cite: 1, 2]
  • Pilihan D2 (Distraksi): x ← x + 1[cite: 1, 2]

Susunan Jawaban Benar (Solusi Algoritma):

  • Bagian Rumpang Kosong 1 diisi dengan Pilihan M1 (x ← i * 2) — Proses inisialisasi nilai putaran per gigi.[cite: 1, 2]
  • Bagian Rumpang Kosong 2 diisi dengan Pilihan M2 (x ← x - 1) — Proses decrement agar perulangan WHILE bernilai konvergen dan bisa berhenti saat x mencapai 0.[cite: 1, 2]

Feedback & Edukasi Visual:

  • Jika Benar: Mekanisme internal brankas berputar secara sinkron, pintu kayu purba bergeser membuka, memunculkan kapsul bercahaya berisi formula pelestarian hayati[cite: 1, 2]. Animasi HUD: "Algoritma tervalidasi! Abstraksi data berhasil menyaring variabel pengganggu. Formula Bio-Preservasi berhasil diselamatkan! Selamat, Anda adalah Detektif Digital Sejati! (+300 Poin)."[cite: 1, 2]
  • Jika Salah (Misal memasukkan variabel tinggi pohon atau menggunakan x ← x + 1): Terdengar bunyi alarm bip-bip mekanis macet[cite: 1, 2]. Edukasi: "Brankas Gagal Terbuka. Melalui teknik Abstraksi, variabel fisik pohon tidak mempengaruhi nilai enkripsi digital, abaikan nilai tersebut! Perhatikan juga struktur WHILE loop: Jika Anda tidak mengurangi nilai x di dalam loop (x ← x - 1), program akan mengalami Infinite Loop (perulangan tanpa akhir) yang membuat sistem gawai crash. Perbaiki urutan instruksimu!"[cite: 1, 2]
